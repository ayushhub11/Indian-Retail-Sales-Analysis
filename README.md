Indian Retail Sales Analysis using Microsoft Excel

Project Overview
This project focuses on analyzing Indian retail sales data using Microsoft Excel. The objective is to understand sales performance, profitability, customer trends, and product performance through data cleaning, formulas, charts, and an interactive dashboard.

Tools Used
- Microsoft Excel
- Excel Tables
- XLOOKUP
- SUMIFS
- Data Cleaning
- Charts and Dashboard

Dataset
The project uses three CSV files:
- List of Orders
- Order Details
- Sales Target

The dataset covers sales transactions from April 2018 to March 2019.

 Data Cleaning and Preparation
- Removed 60 completely blank rows from the orders dataset.
- Organized 500 unique orders.
- Checked duplicate records and missing values.
- Connected order details with customer, date, state, and city information using XLOOKUP.
- Converted the data into structured Excel tables.

 Analysis Performed
1. Monthly Sales and Profit Analysis
2. Category-wise Sales and Profit Analysis
3. Sub-Category-wise Performance Analysis
4. Overall Business Performance Analysis

 Key Business Insights
- Total sales reached ₹4,31,502.
- Electronics recorded the highest category sales of ₹1,65,267.
- Clothing generated the highest category profit of ₹11,163.
- Printers recorded the highest sub-category sales and profit.
- January 2019 recorded the highest monthly sales of ₹61,439.
- November 2018 generated the highest monthly profit of ₹11,619.
- Tables recorded the highest sub-category loss of ₹4,011.
- The business experienced monthly losses from April to September 2018 and monthly profits from October 2018 to March 2019.

Dashboard
The Excel dashboard contains six separate visualizations:
- Monthly Sales
- Monthly Profit
- Category Sales
- Category Profit
- Sub-Category Sales
- Sub-Category Profit

 Recommendations
- Improve overall profit margins through better cost management.
- Focus on profitable products such as Printers and Accessories.
- Investigate losses in Tables and Electronic Games.
- Monitor category-wise profitability.
- Study the reasons behind improved profitability in the later months.

#Conclusion
This project demonstrates how Microsoft Excel can be used to clean, organize, analyze, and visualize retail sales data. The dashboard and business insights help identify sales trends, profitable categories, and areas that need improvement.
